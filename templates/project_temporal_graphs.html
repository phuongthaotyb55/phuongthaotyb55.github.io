Exploring Temporal Graphs with Constraint Programming

{% for tag in ["Python", "NetworkX", "MiniZinc", "Pandas", "NumPy", "Multiprocessing"] %} {{ tag }} {% endfor %}

This project generates temporal graphs and implements multiple algorithms to solve the Temporal Exploration Problem (TEXP): given a temporal graph, find a time-respecting walk starting from node 1 that visits every node within t_max timesteps, or as early as possible. A Max Coverage variant asks the opposite question when t_max is too short: which walk visits the most distinct nodes? The methods are benchmarked on 945 synthetic graphs and applied to a real case study, ScotRail's weekday timetable.

Example temporal graph exploration — the highlighted path shows a valid time-respecting walk visiting every node.
