Fraud Detection on Imbalanced Transactions

{% for tag in ["Python", "scikit-learn", "XGBoost", "imbalanced-learn"] %} {{ tag }} {% endfor %}

Builds a fraud classifier on 284,807 credit-card transactions, where only 0.17% are fraudulent. The project's focus is a leakage-free evaluation pipeline: SMOTE oversampling runs only inside cross-validation, decision thresholds are chosen using out-of-fold training probabilities.

Main findings. At the default 0.5 threshold, SMOTE badly miscalibrates Logistic Regression, that returns the precision to only 5% (F1 0.10), even though it catches 87% of fraud. Tuning the threshold on cross-validated probabilities fixes this almost entirely, and lifting F1 to 0.80 (precision 86%, recall 76%). XGBoost, trained with class-weighting instead of SMOTE, does not suffer this miscalibration in the first place. It reaches F1 0.85 and PR-AUC 0.82 at a far more moderate threshold (0.85), making it the best-performing and most reliable model overall. The comparison across models shows that how you handle class imbalance matters as much as which model you pick.
